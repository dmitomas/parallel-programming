## Поставленные задачи

- Модифицировать программу из Lab1 для параллельной работы по технологии MPI.
- Реализовать распределение строк матрицы A между вычислительными процессами, и сбор результирующих строк матрицы C на главном процессе.
- Засечь время вычислений.

---
## Реализация

- Функция *multiply* адаптирована для перемножения полосы строк `loc_A` (размером `rows × N`) на полную матрицу B (размером `N × N`).
- Вычисленные строки `loc_C` собираются обратно на процессе `rank == 0` в итоговую матрицу C с помощью `MPI_Send` и `MPI_Recv`, после чего результат сохраняется в файл.

### Вывод
Зависимость времени перемножения двух квадратных матриц от их размерности является кубической - O(N³) (т.к. перемножение матриц реализовано при помощи тройного вложенного цикла). Это показывает, что без распараллеливания процессов, при больших размерностях матриц время исполнения задачи будет неоправданно высоко. Следовательно при распараллеливании процессов можно будет значительно сократить время исполнения задачи.
