## Цель лабораторной работы

Написать программу на языке C/C++ для перемножения двух квадратных матриц. Обязательна автоматизированная верификация результатов вычислений с помощью сторонних библиотек или стороннего ПО (например на Matlab/Python).


Исходные данные: файл(ы) содержащие значения исходных матриц([matrix_A.txt](https://github.com/dmitomas/parallel-programming/blob/master/Lab1/assets/data/matrix_A), [matrix_B.txt](https://github.com/dmitomas/parallel-programming/blob/master/Lab1/assets/data/matrix_B)).


Выходные данные: файл со значениями результирующей матрицы, время выполнения, объем задачи и др([result_matrix_C.txt](https://github.com/dmitomas/parallel-programming/blob/master/Lab1/assets/data/result_matrix_C.txt)).

## Поставленные задачи

### На C++
- написать функцию генерации матрицы заданного размера N
- написать функцию записи размерности матрицы и самой матрицы в заданный файл
- написать функцию для перемножения двух матриц
- в функции main сгенерировать матрицы A и B, записать их в файлы [matrix_A.txt](https://github.com/dmitomas/parallel-programming/blob/master/Lab1/assets/data/matrix_A), [matrix_B.txt](https://github.com/dmitomas/parallel-programming/blob/master/Lab1/assets/data/matrix_B) соответственно. Матрицу C являющуюся результатом перемножения матриц A и B записать в файл [result_matrix_C.txt](https://github.com/dmitomas/parallel-programming/blob/master/Lab1/assets/data/result_matrix_C.txt). Засечь время необходимое для перемножения матриц

### На Python
- написать функцию для чтения матрицы размерности N из заданного файла
- считать из файлов [matrix_A.txt](https://github.com/dmitomas/parallel-programming/blob/master/Lab1/assets/data/matrix_A), [matrix_B.txt](https://github.com/dmitomas/parallel-programming/blob/master/Lab1/assets/data/matrix_B) и [result_matrix_C.txt](https://github.com/dmitomas/parallel-programming/blob/master/Lab1/assets/data/result_matrix_C.txt) три матрицы A, B и C соответственно. Перемножить матрицы A и B и сравнить результат с матрицей C при помощи библиотеки numpy
